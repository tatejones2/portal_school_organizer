# Portal School Organizer

A React and Vite website for tracking college baseball transfer portal conversations, offers, program fit, and next steps.

## Run Locally

```bash
npm install
npm run dev
```

The app stores school data in the browser with `localStorage`, so updates remain available between sessions on the same device.

## Deploy to GitHub Pages

This repo includes a GitHub Actions workflow at `.github/workflows/deploy-pages.yml`.
After pushing to `main`, enable Pages in the repository settings and choose **GitHub Actions** as the source.
